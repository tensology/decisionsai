# Documentation index

- `architecture/`: API, control-plane, and frontend design contracts.
- `audits/`: dated audits and evidence-backed remediation findings.
- `operations/`: installation, startup, recovery, and production runbooks.
- `planning/`: implementation and release plans.
- `research/`: strategy studies, backtests, transcript-derived work, and validation results.
- `strategies/`: strategy registry, research policy, and signal-provider rules.
- `ui/`: interface standards and interaction conventions.

Operational truth belongs in `operations/`. Historical findings belong in `audits/`. Generated screenshots and bundles do not belong in this tree.
