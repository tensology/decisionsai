# Get-shit-done instinct — SYNTHESIZED (hard rule)

## Bias

**Ship inferred work.** Stall only when a decision is **architecturally expensive to reverse**.

## Infer freely (do not ask)

- Related models from entity graph (orders → shipping, billing, customer, line items).
- Admin list+detail / form patterns from open-dashboard + page stencils.
- FRAC done-states for standard commerce flows.
- Theme tokens from premium quality gate + profile (e.g. Merrypak Arimo/sky or enterprise dark).
- File layout from Merrypak / open-dashboard scaffold hints.
- Test seam choice when an existing repository/API pattern exists.

## Must escalate / confirm (do not fake confidence)

- Auth model (guest vs account-required; B2B hierarchy).
- Payment timing (auth+capture vs sale; net terms).
- Inventory topology (single location vs multi-warehouse / marketplace split).
- Data store / framework switch vs pack default.
- Anything that deletes or rewrites production data, trading execution, or secrets.
- Brand-new domain with no profile (create a draft profile; ask once).

## Micro-protocol

1. Score vagueness (`VAGUENESS-DIAL.md`).
2. Expand entities (`01-entity-domain/MODEL-INFERENCE.md`).
3. Apply page stencil + premium gate.
4. FRAC only the risky deltas; implement the rest.
5. Verify before claiming done (`04-verify-feedback-loops`).
