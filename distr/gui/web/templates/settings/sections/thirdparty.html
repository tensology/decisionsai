API Keys

Configure API keys for external services

KiloCode:
Get your KiloCode API key from Kilo.ai → Dashboard → API Keys
Google Gemini:
Get your Gemini API key from Google AI Studio → Get API Key
ElevenLabs:
Get your ElevenLabs API key from ElevenLabs → Profile Settings → API Keys
AssemblyAI:
Get your AssemblyAI API key from AssemblyAI Dashboard → Settings → API Keys
OpenAI:
Get your OpenAI API key from OpenAI Platform → API Keys → Create new secret key
Anthropic:
Get your Anthropic API key from Anthropic Console → Settings → API Keys
Cursor:
Get your Cursor API key from Cursor Dashboard → API Keys
Composio:
Powers Composio Connect MCP in Cursor/Codex (1000+ apps). Rube is deprecated — not configured. Get your key from platform.composio.dev → Project Settings → API Keys. Decisions injects it into your IDE MCP config on save — no manual mcp.json editing.
OpenRouter:
Get your OpenRouter API key from OpenRouter → Keys → Create New Key
Groq:
Get your Groq API key from Groq Console → API Keys → Create API Key
NVIDIA:
Get your free API key at build.nvidia.com → avatar → API Keys → Generate API Key (enable Public API Endpoints). Enable the checkbox, paste the key, click Validate (saves automatically).
Pixazo:
Get your API key at api-console.pixazo.ai — one key for image, video, and audio models. Browse models at pixazo.ai/models. Validate saves automatically.
Masko AI:
Get your Masko API key from Masko.ai → Dashboard → API Keys. Used for AI skin generation.
