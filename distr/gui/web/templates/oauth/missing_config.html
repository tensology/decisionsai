Go to Google Cloud Console

Setup Instructions:

1. Create OAuth 2.0 Client ID

Click "Create Credentials" → "OAuth client ID" → Select "Web application"

2. Add Authorized JavaScript origins

In the "Authorized JavaScript origins" section, add:

{javascript_origin}

3. Add Authorized redirect URIs

In the "Authorized redirect URIs" section, add:

{redirect_uri}

4. Enable Required APIs

You must enable the following APIs in Google Cloud Console for full functionality:

Enable Gmail API Enable Google Drive API Enable Google Calendar API Enable Google Docs API

Click each button above to enable the required APIs. After enabling, wait a few minutes for changes to propagate.

5. Download JSON File

After creating the OAuth client, click the download button to save your google_oauth_client_secret.json file.
