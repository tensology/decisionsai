# DecisionsAI 2.9.0 warning ledger

The 2026-07-17 default gate passed with 1,293 warnings. Warnings are not treated
as test success, but they are separated here from release-blocking failures so
the remaining cleanup is explicit and measurable.

## Release-relevant warnings

- Python 3.12 deprecates `datetime.utcnow()`. Runtime occurrences remain in the
  scheduler, Initiative scanner/service, automation store, chat trace, Google
  Workspace refresh, project handoff, and a few ticket timestamps. These are
  compatible on the supported 3.12 runtime but must move to one project-wide
  UTC helper before Python 3.14 support is considered.
- FastAPI's `on_event` startup hooks are deprecated. The server still starts
  correctly, but those hooks should be consolidated into a lifespan context.
- One workflow update route still uses Pydantic v1-style `dict()` and should use
  `model_dump()` before Pydantic v3.

## Test-harness-only warnings

- The dominant group (roughly 940 warnings) is Python 3.12's deprecated default
  SQLite datetime adapter in migration property tests. Production migration
  behavior passes, but the test database should register explicit datetime
  adapters/converters.
- Several legacy/manual smoke tests return booleans instead of asserting and
  returning `None`.
- A synthetic AEC test uses `asyncio.get_event_loop()` without an active loop.
- PyInstaller reports optional/platform-specific modules and native libraries
  while tracing the broad dependency environment (for example Windows/Linux
  libraries, optional Torch `libsox`, and MLX). The isolated 2.9.0 app build,
  install, version verification, web/database smoke, and helper cleanup all
  passed; these messages remain packaging-noise cleanup rather than a hidden
  successful-signing claim.

## Reduced in this candidate

- Collection no longer mistakes `PipelineAgentSession` for a pytest class.
- Empty paid/free model recommendation lanes are normalized to unavailable
  instead of logging three misleading missing-field warnings per lane.
- The workflow migration marker no longer calls deprecated `utcnow()`.
- `browser_ui` is a supported Playwright validation alias, so a valid workflow
  step no longer logs an unknown-validation warning.

The warning count is a cleanup baseline, not a claim that every deprecation has
been resolved. None of the remaining warnings may be promoted to an exception
without adding or updating the corresponding migration first.
