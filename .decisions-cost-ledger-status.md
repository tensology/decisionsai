## How to open Costs tab

1. Open Development in the local web UI.
2. Sidebar → **Reports**.
3. Click the **Costs** tab (beside Run history / Time log).
4. Toggle **Display**: Blended (default, one cost figure) or Explicit (tokens + provider USD + local resource USD).
5. Refresh reloads `GET /workflows/studio/reports/costs?rollups=true&display=…`.

Disable recording: env `DECISIONS_COST_LEDGER_ENABLED=0` (or settings key when ORM column exists).
